Notes:

- Each numbered module follows the same high-level shape: `README.md`, `learning-materials/`, `simple-tasks/`, and `pet-projects/`.
- `16-cloud-databases/` is a numbered container, not a technology module; each child database directory follows the module shape and owns its `PROGRESS.md`.
- `scripts/` contains one-time module scaffolding, read-only validation, and learner-copy export tools; live repository files are the source of truth.
- `docs/` is the repository-level navigation and architecture layer.
- `real-projects/` is the multi-technology portfolio layer.
- `10-powerbi-fabric/`, `13-flink/`, and `14-iceberg/` exist as planned future placeholders and are intentionally outside the current active learning scope.
