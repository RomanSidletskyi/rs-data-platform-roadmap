# Cloud Databases

This learning block groups cloud database platforms under one stable repository area. Each database is a self-contained learning module with its own materials, practice, projects, and progress tracker.

## Modules

### 01 Snowflake

[Open the Snowflake module](01-snowflake/README.md) for a detailed path from cloud data warehouse foundations to production platform architecture.

The module is intentionally standalone. It teaches Snowflake as a platform, not as a short extension of generic SQL material.

## Adding Another Cloud Database

Create a sibling directory such as `02-bigquery/` or `03-redshift/`. Each child should use the same module shape:

- `README.md`
- `learning-materials/`
- `simple-tasks/`
- `pet-projects/`
- `PROGRESS.md`

Keep platform-specific material in its child module. Use this README only for block-level navigation and comparisons across cloud databases.
