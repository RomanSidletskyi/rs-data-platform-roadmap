# Task Set 06: Security, Recovery, and Architecture

## Task 1: Secure View or Policy?

A partner needs three columns from a sensitive customer dataset and must not see inactive customers. Compare a secure view, masking/row policies, and a separate curated table.

## Task 2: Access Review

List the grants and role paths to test for a new read-only analytics role, including future objects.

## Task 3: Choose Recovery Controls

Map accidental update, bad deployment, source corruption, and regional outage to appropriate recovery mechanisms and their limits.

## Task 4: Region Design

A service must meet a four-hour recovery time and tolerate a regional disruption. List the system components that must be included beyond data replication.

## Task 5: Architecture Review

Propose one Snowflake topology for dev/test/prod. State the assumptions, alternatives, trade-offs, failure modes, and evidence needed to revisit your choice.
