# Task Set 05: Performance and Cost

## Task 1: Queueing or Slow Execution?

## Task 2: Broad Scan

A query filters by date but scans most table partitions. List evidence to inspect before choosing clustering or a larger warehouse.

## Task 3: Warehouse Size

A query is CPU-heavy, has no queueing, and benefits from a larger warehouse in a controlled test. What else must be measured before rollout?

## Task 4: Cache Effect

A benchmark is fast on its second run. Explain why this is insufficient evidence for a production performance claim.

## Task 5: Cost Guardrail
