# Snowflake Learning Materials

This folder contains the shared Snowflake curriculum. **All topics and files are available to all learners.** Junior, Middle, Senior, and Architect are lenses for choosing a useful depth and focus, not separate or gated syllabi.

## How to Navigate

Use these three documents for different questions; they are not competing catalogs:

1. **What material exists?** Open the [Capability Map](00_snowflake_capability_map.md). It is the canonical, topic-organized inventory and links directly to every learning-material file in this folder.
2. **How should I approach each topic at my level?** Open [Learning Paths](01_learning_paths.md). It covers the shared curriculum and gives all four levels a focus for every topic. A Senior can revisit fundamentals; a Junior can preview advanced design material.
3. **In what sequence should I study and practice?** Open the [Snowflake Platform Learning Guide](snowflake_platform_learning_guide.md). It lays out the course phases, outcomes, activities, and completion evidence; it does not maintain a second copy of the complete file catalog.

If you are unsure where to begin, follow the Guide's phases. If you already have a specific question, go directly to the Map and use the Learning Paths table to decide how deeply to study the linked material.

## Material Collections

- [Quick references](reference/README.md): concise syntax, functions, object types, loading, processing, and recovery.
- [Deep dives](deep-dives/README.md): behavior, worked examples, limitations, and alternatives.
- [Query performance and optimization](deep-dives/query-performance/README.md): diagnosis, metrics, SQL patterns, caches, costed features, production cases, and architecture decisions.
- [Iceberg and External Tables](deep-dives/iceberg-and-external-tables/README.md): table-pattern comparison, catalog ownership, refresh, and detailed guides.
- [Architecture guides](architecture/README.md): platform boundaries, options, consequences, and decision checklists.

These collection READMEs are useful sub-indexes. The Capability Map remains the complete file-level catalog.

## Keeping Navigation Complete

When adding, moving, or renaming a learning document:

1. Add or update its direct link in the relevant Capability Map topic and complete material index.
2. Add it to the relevant shared topic in Learning Paths and state the focus for Junior, Middle, Senior, and Architect.
3. Update the Learning Guide only if the material changes the recommended sequence, learning outcomes, practice, or checkpoints.
4. Update this page or the module README only when navigation structure or collection membership changes.

Level guidance must never imply that material is unavailable to another level. Use recommendations such as **learn**, **apply**, **diagnose**, **design**, **review**, or **optional deep dive** to communicate depth.
