## First-Pass Scope

The first pass prioritizes a usable path from foundational concepts to architecture decisions. It intentionally provides a broad capability inventory and focused treatment for high-impact topics rather than attempting to exhaust every product feature. Expand a topic when a concrete learning or design question appears.
